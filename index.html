localhub

Shows which local ports currently serve a web page.

Notes

The scan runs entirely in your browser (fetch to http://localhost:PORT), nothing is sent to a server. Chrome and Edge may ask once for permission to access local network devices, allow it. Safari blocks HTTP requests from HTTPS pages, so open the page locally there. The title is only shown if the dev server allows CORS (Vite and webpack-dev-server usually do). Servers that only speak HTTPS or no HTTP at all (databases etc.) are not detected.
